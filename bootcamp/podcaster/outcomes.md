# What Can You Build Now?

You've built a multi-agent podcast production system: one agent researches, another turns raw findings into a report, a scriptwriter turns that report into dialogue, and a custom voice tool generates audio.

Here are **10 real-world projects** you can build with the same architecture.

---

## 1. Daily Tech News Podcast

> Turn the latest technology news into a short daily show.

|                       |                                                                                                                                                                                                                                      |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **What it does**      | **Agent 1** searches for the latest technology stories. **Agent 2** filters them into a coherent daily briefing. **Agent 3** writes a 5-minute script. **Agent 4** generates the audio episode.                                      |
| **Why it matters**    | Tech newsletters and podcasts compete on speed and clarity. A daily AI-assisted production workflow can reduce hours of research and scripting into minutes.                                                                         |
| **Skills you'll use** | Web search tools, sequential context passing, script generation, Gemini TTS, reusable topic inputs.                                                                                                                                  |
